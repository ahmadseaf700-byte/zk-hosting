# ZK Hosting

لوحة تحكم أولية لمنصة استضافة Minecraft تعتمد على أن يكون هاتف المستخدم هو مضيف السيرفر، بينما تستضيف Render لوحة التحكم وواجهات الـ API.

## التشغيل محلياً
يتطلب Node.js 20 أو أحدث.

```bash
npm start
```

ثم افتح `http://localhost:3000`.

## إعداد Render
- Environment: Node
- Branch: `main`
- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: اتركه فارغاً

## الحالة الحالية
- صفحة لوحة تحكم عربية متجاوبة.
- فحص صحة الخدمة عبر `GET /api/health`.
- إنشاء وعرض سجلات سيرفرات تجريبية عبر `/api/servers`.
- السجلات محفوظة في ذاكرة العملية فقط، وتُمسح عند إعادة تشغيل الخدمة.
- لا يوجد بعد تطبيق Android Agent، أو تشغيل فعلي لمحركات Minecraft، أو قاعدة بيانات، أو نظام حسابات ومصادقة.

## خارطة الطريق
1. إضافة قاعدة بيانات ومصادقة آمنة للمستخدمين.
2. بناء تطبيق Android Agent وربطه باللوحة عبر رمز اقتران آمن.
3. تنفيذ إدارة عمليات Java وBedrock على الهاتف.
4. اختبار الاتصال الخارجي، خصوصاً NAT/CGNAT واتصالات TCP وUDP.
5. إضافة سجلات التشغيل والملفات والإضافات وإدارة الموارد.
