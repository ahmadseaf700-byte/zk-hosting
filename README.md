# DragonHost 🐉

لوحة تحكم عربية لبناء وإدارة استضافة Minecraft، مع تصميم مرحلي يفصل لوحة التحكم عن جهاز تشغيل السيرفرات.

## التشغيل
يتطلب Node.js 20 أو أحدث.

```bash
npm start
```

ثم افتح `http://localhost:3000`.

## إعداد Render
- Environment: Node
- Branch: `main`
- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: اتركه فارغاً
- أضف Persistent Disk بمسار `/var/data` واضبط `DATA_DIR=/var/data` للحفاظ على ملف البيانات.

## المنجز في v0.4.0
- تسجيل حساب وتسجيل دخول وخروج.
- حفظ الحسابات والسيرفرات في ملف JSON.
- لوحة تحكم عربية Dark Mode ومتجاوبة مع الهاتف.
- معالج إنشاء سيرفر من أربع خطوات.
- فحص توفر subdomain من الخادم قبل الإنشاء.
- إعدادات Java/Bedrock والنواة والإصدار وMOTD.
- إعدادات وضع اللعب والصعوبة وعدد اللاعبين وOffline Mode وPvP والطيران.
- تحقق من المدخلات على الخادم وربط ملكية السيرفر بالحساب.
- واجهة Console أولية توضّح صراحة أن Agent غير متصل ولا ترسل أوامر وهمية.

## حدود النسخة الحالية
إنشاء السيرفر يحفظ إعداداته فقط. لا يتم حالياً تنزيل server.jar أو قبول EULA أو تشغيل Minecraft. قائمة الإصدارات ثابتة ومبدئية. أقسام الملفات والإضافات واللاعبين والنسخ الاحتياطية واجهات قيد التطوير. لا تفتح المنصة للعامة قبل استكمال قاعدة بيانات إنتاجية، وإدارة الجلسات، وحماية CSRF، وعزل جهاز الاستضافة، ومراجعة الأمان.

## خارطة الطريق
1. ربط Hosting Agent آمن على Android/Linux مع طابور مهام وحالة اتصال.
2. تشغيل وإيقاف السيرفرات فعلياً وإرسال السجلات عبر WebSocket.
3. RCON آمن لتنفيذ أوامر Minecraft.
4. مدير ملفات ومحرر إعدادات بصلاحيات ومسارات محصورة.
5. تكامل Modrinth لتثبيت الإضافات والمودات.
6. إدارة اللاعبين والعوالم والنسخ الاحتياطية.
7. إحصائيات الموارد والإيقاف التلقائي.
